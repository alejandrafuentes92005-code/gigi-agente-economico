# 🐧 Gigi - Agente Económico de IA

Gigi es una interfaz web interactiva desarrollada con **Streamlit** y **Python** que integra 6 APIs económicas globales para resolver consultas financieras y macroeconómicas en tiempo real.

## 🛠️ APIs Integradas
- 💱 Open Exchange Rates (Tipos de cambio)
- 🪙 CoinGecko (Criptomonedas)
- 🌐 Banco Mundial (Indicadores de desarrollo)
- 🗺️ Countries.dev (Información de países)
- 🏛️ U.S. Treasury (Deuda pública de EE. UU.)
- 📦 UN Comtrade (Comercio internacional)
